## Установка и запуск

1. **Клонирование репозитория:**
   ```bash
   git clone [repository-url]
   cd sacramento-appliance-pro
   ```

2. **Запуск локального сервера:**
   ```bash
   # Используя Python
   python -m http.server 8000
   
   # Или используя Node.js
   npx serve .
   
   # Или используя PHP
   php -S localhost:8000
   ```

3. **Открытие в браузере:**
   ```
   http://localhost:8000
   ```
