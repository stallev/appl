# Концепция дизайна сайта для ремонта электроники

## Общая концепция
Профессиональный, современный и доверительный сайт для индивидуального предпринимателя по ремонту электроники в Sacramento, CA. Дизайн должен передавать надежность, профессионализм и доступность услуг.

## Целевая аудитория
- Жители Sacramento и окрестностей
- Владельцы бытовой техники (холодильники, стиральные машины, посудомоечные машины, микроволновки, духовки)
- Коммерческие клиенты (рестораны, офисы)
- Возраст: 25-65 лет
- Доход: средний и выше среднего

## Цветовая палитра
- **Основной цвет**: #2C5F2D (темно-зеленый) - надежность, природа, рост
- **Акцентный цвет**: #FF6B35 (оранжевый) - энергия, тепло, срочность
- **Нейтральный**: #F7F7F7 (светло-серый) - чистота, профессионализм
- **Текст**: #2C2C2C (темно-серый) - читаемость
- **Белый**: #FFFFFF - чистота, простота

## Типографика
- **Заголовки**: 'Inter', sans-serif (современный, читаемый)
- **Основной текст**: 'Inter', sans-serif
- **Размеры**: 16px базовый, 24px заголовки, 32px главные заголовки

## Визуальные элементы
- **Иконки**: Material Icons (профессиональные, понятные)
- **Изображения**: высококачественные фото ремонта, инструментов, довольных клиентов
- **Градиенты**: тонкие переходы от основного к акцентному цвету
- **Тени**: мягкие тени для глубины

## UX/UI принципы
1. **Простота навигации** - максимум 3 клика до любой информации
2. **Четкие CTA** - яркие кнопки "Заказать ремонт", "Позвонить"
3. **Мобильный приоритет** - все функции доступны на телефоне
4. **Быстрая загрузка** - оптимизированные изображения
5. **Доверие** - отзывы, сертификаты, гарантии

## Эмоциональное воздействие
- **Надежность** - через профессиональные фото и отзывы
- **Срочность** - через акцентные цвета и CTA
- **Доступность** - через простой язык и понятную навигацию
- **Экспертность** - через детальную информацию об услугах

## Адаптивность
- **Mobile First** - приоритет мобильной версии
- **Breakpoints**: 320px, 768px, 1024px, 1200px+
- **Touch-friendly** - большие кнопки и ссылки на мобильных
- **Читаемость** - оптимальные размеры шрифтов для каждого устройства

## SEO и конверсия
- **Локальный SEO** - оптимизация под Sacramento, CA
- **Скорость загрузки** - Core Web Vitals
- **Структурированные данные** - для лучшего понимания поисковиками
- **Конверсионные элементы** - формы, телефоны, чаты
